## 目标与范围
实现 React + TypeScript + Vite 网页桌面游戏，三方向、三导师、十二种核心软件与规则模拟 AI 助手。四周内可完成阅读、选题、编程、排队训练、分析、论文投稿与修改，并处理 NPC、组会、精力和职业选择。

## 验收标准
- 可创建身份，窗口可打开、拖动、切换、最小化和最大化。
- 所有操作有实际效果，实验与 NPC 在时间推进中持续运行。
- 文献、方案、GPU、分析、论文、审稿数据相互联动。
- 实验失败有配置原因和可操作诊断，同种子可复盘。
- 可游玩 28 天并结算多维成果；本地自动及手动存读档保留核心状态。
- 类型检查、构建、核心引擎测试和浏览器交互验证分别记录。
