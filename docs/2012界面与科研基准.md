# 2012 界面与科研基准

本项目更名为《研究生桌面模拟器：2012》。桌面基础系统对齐本地参考项目《大学生桌面模拟器：2012》，保留研究生科研体验闭环，不复制其本科生活规则。

## 桌面与软件

- Windows 7 Harmony 蓝色壁纸、真实系统图标、40px Aero 任务栏、开始圆球、双栏开始菜单、系统托盘、桌面便笺与时钟。
- Aero 标题栏、右上角最小化/最大化/关闭、窗口拖动、右下角缩放、任务栏切换与显示桌面。
- 研究程序采用同期的软件语境：QQ2012、Internet Explorer 9、文献管理、Vim 7.3/Python 2.7、PuTTY 0.62、Word 2010、Outlook 2010，以及蓝白灰工具栏、列表和分栏。
- 科研工具箱是本地脚本与格式整理，不是生成式 AI。第三方代码、导入引用和统计解释仍然需要核验。

三方向调整为机器学习与模式识别、自然语言处理与信息检索、分布式系统与数据处理。游戏论文仍为虚构文献，历史资料只用于约束方法和设备，不把虚构论文当作真实学术结果。

## 兼容与边界

- 既有 v1 档不因主题切换丢失。旧版系统文本迁移，用户自由文稿和聊天保持原文，并提供原始存档备份导出。
- 旧版无法满足新设备显存限制的运行任务会给出迁移说明，保留原任务记录与已消耗资源。
- 游戏的 4 周科研周期、后台任务、论文评审、NPC 与精力系统仍使用同一时间引擎。2012 年代化不是只替换年份和壁纸。
